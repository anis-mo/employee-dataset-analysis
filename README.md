# 👔Employee Data Analysis

## 📌Project Overview

This project analyzes an employees dataset using Microsoft Excel to explore employee demographics, salaries, departments, regions, employment status, emote work, and performance.

The project includes data cleaning, PivotTables, data analysis, and an interactive dashboard.

---

## Objectives

The objective of this project is to transform raw emlpoyee data into a clean and structured dataset, analyze employee and salary patterns the results in a clear and professional way.

## 🗒️Dataset

The dataset contains transaction-level information about cafe sales:

- Employee_ID
- First_Name
- Last_Name
- Age
- Department
- Region
- Status
- Join_Date
- Salary
- Email
- Phone
- Performance_Score
- Remote_Work

## 🧹Data Cleaning

The first stage focused on preparing the raw employee data for analysis :

- Checked for duplicate emlpoyee records.
- Checked for missing and blank values.
- Replaced "N/A" values in numerical columns such as "Salary" with blanks.
- Kept missing numerical values blank instead of replacing them with zero.
- Cleaned inconsistent values in the "Region" column.
- Removed hidden spaces and unwanted characters from text values.
- Checked and corrected data types.
- Formatted "Join_Date" as Date.
- Formatted "Salary" as Number.
- Treated "Phone" as Text rather than numerical field.
- Converted Remote_Work values into a numerical indicator for KPI calculation.
- Removed unnecessary index information such as "Unnamed : 0" where applicable.
- Converted the dataset into and Excel Table.

---

## PivotTables Analysis

After cleaning the data, PivotTables were created to answer the main analysis questions.

## 🔎Analysis Questions

- Which departments have the highest average salary ?
- How many employees are in each department ?
- How many employees distributed by employent status ?
- How does remote work affect average salary ?
- Which regions have the highest average salary ?
- How does performance score relate to average salary ?

These questions were used to create six PivotTables for the dashboard analysis.
